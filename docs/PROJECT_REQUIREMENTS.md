# Cap Selling Website

## 1. Project Overview

A modern e-commerce website for selling caps online.

The website should allow customers to:

* Browse different caps
* View cap details
* Select quantity
* Add products to cart
* Place an order
* View product prices and availability

## 2. Target Users

* Students
* Young customers
* People interested in fashion and casual wear

## 3. Main Features

### Home Page

* Brand logo
* Navigation bar
* Hero section
* Featured caps
* Categories
* Call-to-action buttons

### Product Page

* Cap image
* Cap name
* Price
* Description
* Available colors
* Available sizes
* Add to Cart button

### Shopping Cart

* Selected products
* Quantity control
* Product price
* Total price
* Remove product option

### Checkout

* Customer name
* Phone number
* Address
* City
* State
* Pincode
* Order summary
* Place Order button

## 4. Product Categories

* Baseball Caps
* Snapback Caps
* Sports Caps
* Casual Caps
* Premium Caps

## 5. Technology

### Frontend

* HTML

* JavaScript

### Backend

* Python

### Database

* SQLite initially

## 6. Future Features

* User accounts

* Product management

## 7. Design Requirements

The website should be:

* Responsive
* Mobile friendly

## 8. Project Goal

Build a complete working e-commerce website that can later be expanded into a real cap-selling business.
